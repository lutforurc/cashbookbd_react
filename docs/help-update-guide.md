# Help-এর লেখা বদলানোর সহজ নির্দেশিকা

এই নির্দেশিকাটি লেখার জন্য, কোড জানার দরকার নেই। Help-এর সব লেখা থাকে
`public/help/` ফোল্ডারের JSON ফাইলে। শুধু লেখা বদলালে কোড বদলাতে হয় না।

## ১. কোন মডিউলের ফাইল কোথায়

| মডিউল | ফাইল |
| --- | --- |
| বিক্রি (Sales) | `public/help/sales.json` |
| ক্রয় (Purchase) | `public/help/purchase.json` |
| আদায় (Collection) | `public/help/collection.json` |
| পরিশোধ (Payment) | `public/help/payment.json` |
| লেজার (Ledger) | `public/help/ledger.json` |
| ক্যাশ ও ব্যাংক বই | `public/help/cash-book.json` |
| রিপোর্ট | `public/help/reports.json` |
| অ্যাসেট | `public/help/assets.json` |

কোন মডিউলে কোন বিষয় আছে, তার তালিকা `public/help/index.json`-এ থাকে।

## ২. লেখা বদলানো

1. উপরের তালিকা থেকে সঠিক ফাইলটি খুলুন (Notepad, VS Code বা যেকোনো টেক্সট এডিটরে)।
2. যে বাক্যটি বদলাবেন, তার দুই পাশে থাকা `" "` (কোট) মুছবেন না।
3. শুধু কোটের ভেতরের লেখাটুকু বদলে ফাইলটি সেভ করুন।
4. `updated` ঘরে আজকের তারিখ লিখুন, যেমন `"06/11/2026"` — এটি Help-এ ছোট করে দেখাবে।

## ৩. সতর্কতা যোগ করা

যে ধাপে সতর্কতা দেখাতে চান, সেই ধাপের ভেতরে এই লাইনটি যোগ করুন:

```json
"warning": "এখানে সতর্কতার কথাটি লিখুন।"
```

আগের লাইনের শেষে কমা (`,`) আছে কিনা দেখে নিন। শেষ লাইনে কমা লাগে না।

## ৪. ভিডিও যোগ করা

যে বিষয়ে ভিডিও দেখাতে চান, তার `"video": ""` ঘরে লিংকটি বসান:

```json
"video": "https://www.youtube.com/watch?v=XXXXXXXX"
```

YouTube লিংক হলে Help-এর ভেতরেই ভিডিও চলবে। অন্য লিংক হলে "ভিডিও দেখুন"
লেখা একটি লিংক আসবে। লিংক না থাকলে ঘরটি খালি রাখুন — কিছুই দেখাবে না।

## ৫. নতুন বিষয় যোগ করা

1. সংশ্লিষ্ট মডিউল ফাইলে একটি নতুন বিষয় লিখুন। যেমন:

```json
"new-topic-id": {
  "title": "নতুন স্ক্রিনের নাম",
  "module": "Sales",
  "updated": "06/11/2026",
  "businessTypes": ["all"],
  "video": "",
  "intro": "এই স্ক্রিনে কী হয়, দুই-তিন বাক্যে লিখুন।",
  "sections": [
    {
      "heading": "ধাপ ১: কাজ শুরু",
      "menu": "Menu → যে মেনুপথ",
      "steps": ["প্রথম কাজ।", "দ্বিতীয় কাজ।"],
      "warning": "দরকার হলে সতর্কতা।"
    }
  ]
}
```

2. `public/help/index.json`-এ সংশ্লিষ্ট মডিউলের `"topics"` তালিকায় নতুন
   `new-topic-id`-টি যোগ করুন।
3. নতুন স্ক্রিনে Help বাটন বসাতে ওই স্ক্রিনের ফাইলে এক লাইন
   `<HelpButton topic="new-topic-id" />` যোগ করতে হয়। আলাদা কোনো জানালা বা
   কোড বানাতে হয় না — সব স্ক্রিন একই Help জানালা ব্যবহার করে।
4. `docs/help-coverage.md`-এ নতুন route-এর সারি যোগ করুন (Screen, Menu path,
   Route, Topic, Status)। নতুন route এলে এই সারি না থাকলে `help:check` ব্যর্থ হবে।

## ৬. নতুন স্ক্রিনে বাটন

দুটি উপায়, যেটি সহজ সেটি:

- ওই স্ক্রিনের ফাইলে `<HelpButton topic="new-topic-id" />` বসান (আগে
  `../../help/HelpButton` ইমপোর্ট করুন)। এটি সবচেয়ে স্পষ্ট।
- অথবা `src/components/help/helpTopicForPath.ts`-এ
  `'/screen/route': 'new-topic-id',` যোগ করুন। তখন layout-এর ভাসমান `?` ওই
  স্ক্রিনে দেখা যাবে, স্ক্রিনের ফাইল বদলাতে হবে না।

দুটো একসাথে করবেন না — তাহলে দুটো `?` দেখাবে।

## ৭. ফাঁকা ঘর

`menu`, `steps`, `table`, `warning`, `video` — যেটি খালি বা বাদ দেওয়া হবে,
Help-এ সেটি দেখাবে না। শুধু `heading` সবসময় থাকতে হবে।

## ৮. যাচাই করা

কম্পিউটারে প্রজেক্ট ফোল্ডার খুলে এই কমান্ড চালান:

```bash
npm run help:check
```

সব ঠিক থাকলে "Help যাচাই ঠিক আছে" লেখা আসবে। কোনো ভুল থাকলে কোন ফাইলে কী
সমস্যা তা বলে দেবে; সেটি ঠিক করে আবার চালান।

## ৯. কখন ক্লায়েন্টের কাছে যাবে

লেখা সেভ করলেই ক্লায়েন্টের স্ক্রিনে বদলাবে না। স্বাভাবিক React আপডেট
(বিল্ড ও ডিপ্লয়) হলে নতুন লেখা সবার কাছে যাবে। তার আগে নিজের কম্পিউটারে
Help খুলে দেখে নিতে পারেন।
