# Taste
- Expects keyboard shortcuts to behave consistently across data-entry screens — Ctrl+S saves, Ctrl+U updates — so a newly wired form matches a screen where the shortcut already works (e.g. Cash Received) instead of getting its own variant. Confidence: 0.55
- Expects Enter in a list/report search box to run the search exactly as that screen's Search/Apply button does — same handler, same filters, same paging reset — and asks for it as a short standing fix ("Search এ Enter দিলে যেন রান হয়"), coming back with the same request for each screen that still lacks it rather than accepting a mouse-only search. Confidence: 0.6
- Optional numeric charge fields on an entry form start genuinely empty — a blank box — rather than pre-filled with `0`, including on an existing record that has no value in that field; the blank is coerced to `0` only for calculations and in the save payload so the API never receives null. Confidence: 0.5
- A dropdown/select filter is a strict narrowing, not a hint: picking a Product in a report filter must return only that product's rows, and complains when a selection still yields many results ("Product এটা দিয়ে সার্চ দিলে শুধুমাত্র ঐ Product দেখাবে… অনেকগুলো দেখাচ্ছে কেন?"); broad/multiple matches are the free-text Search box's job ("যদি Search এখানে দেয় তবে অনেকগুলো দেখাতে পারে"), so the two inputs must not resolve to the same loose match. Confidence: 0.6
- List-row actions are plain coloured icons, not filled buttons: the row action is a background-free icon (e.g. a larger pen for edit) carrying just a tooltip, and the same treatment is expected on every list screen — wants it changed, then asks for the remaining lists to match it ("Designation Level List, Designation List দুটোতেই ঠিক করে দাও"). Confidence: 0.6
- A value already agreed on a source document is immutable downstream: an invoice raised from an order must keep the order's rate and must not let it be edited (the correction: "Rate Update করা যাবে না। কারণ রেট অর্ডারে দেয়া আছে।"), with the field shown read-only in the table and entry form and the same rule enforced server-side, while the fields that legitimately vary (quantity, within the remaining limit) stay editable. Confidence: 0.55
- The local (Bangla) name of a record is shown only when BOTH hold: the company has the local language switched on, and that record actually has a local name. No local name means nothing is drawn — no blank line, dash, or placeholder — and the English name stands alone, in the dropdown list and in the picked/closed value alike; states the rule as a standing condition ("কোম্পানিতে বাংলা চালু থাকলে এবং বাংলা থাকলে তবেই দেখাবে, বাংলা না থাকলে দেখাবে না"). Confidence: 0.6
- Commits happen only when the owner asks. Finishing a piece of work is not a reason to commit; leave it in the working tree and wait for the word (commit / কমিট কর), then commit whatever is outstanding. Confidence: 0.9
